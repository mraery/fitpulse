## 🌟 Temel Özellikler

- **🏋️‍♂️ Hazır Split Antrenman Şablonları:**
  - **Push (İtiş):** Bench Press, Incline Dumbbell Press, Overhead Press, Triceps Pushdown.
  - **Pull (Çekiş):** Deadlift, Lat Pulldown, Barbell Biceps Curl.
  - **Legs (Bacak):** Back Squat, Romanian Deadlift, Calf Raise.
- **⏱️ Entegre Dinlenme Sayacı (Rest Timer):**
  - Set aralarında 60s, 90s, 120s geri sayım ve sesli/görsel uyarı.
- **🧮 1RM (Tek Tekrar Maksimumu) Hesaplayıcı:**
  - Epley bilimsel formülü ile tek seferde kaldırabileceğiniz maksimum ağırlığı ve kuvvet/hipertrofi yüzdelerini hesaplama.
- **⚖️ Barbell Plaka Dağılım Hesaplayıcı:**
  - Hedeflenen ağırlık için olimpik bara (20kg) her iki taraftan hangi plakalardan kaçar tane takılması gerektiğini görsel olarak gösterme.
- **💧 Günlük Su Tüketim Takibi:**
  - 3000 ml günlük su hedefi, 250ml/500ml/1000ml hızlı ekleme butonları ve ilerleme çubuğu.
- **📈 Antrenman Geçmişi & Hacim Takibi:**
  - Her antrenmanda kaldırılan toplam ağırlık hacmini (Volume kg) ve tamamlanan setleri kaydetme.
- **🔒 %100 Çevrimdışı ve Güvenli:**
  - İnternetsiz spor salonlarında dahi kusursuz çalışır, verileriniz cihazınızda saklanır.

## 📱 İndirme & Kurulum

Android için derlenmiş hazır APK dosyasını doğrudan [Releases](https://github.com/mraery/fitpulse/releases) sayfasından indirebilirsiniz.

```bash
# Projeyi klonlayın
git clone https://github.com/mraery/fitpulse.git

# Paketleri yükleyin
flutter pub get

# Uygulamayı çalıştırın
flutter run
```
